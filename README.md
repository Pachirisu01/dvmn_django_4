# Карта покемонов в Москве

Django-приложение для отображения на карте покемонов (особей) с учётом времени их появления. Реализованы страницы со списком покемонов и детальная страница каждого покемона с эволюциями.

### Как установить
- Клонируйте репозиторий и зайдите в папку проекта.
- Создайте виртуальное окружение и активируйте его:
```
python -m venv venv
venv\Scripts\activate
```

#### Примените миграции
```
python manage.py makemigrations
python manage.py migrate
```

#### Создайте суперпользователя для доступа в админку
```
python manage.py createsuperuser
```

#### Запустите сервер разработки
```
python manage.py runserver
```
Затем откройте в браузере http://127.0.0.1:8000/ 

## Модели данных

### `Pokemon` - вид покемона
| Поле | Тип | Описание |
|------|-----|----------|
| `title` | `CharField` | Название на русском (основное) |
| `title_en` | `CharField` | Английское название (необязательное) |
| `title_jp` | `CharField` | Японское название (необязательное) |
| `description` | `TextField` | Текстовое описание покемона |
| `pokemon_image` | `ImageField` | Загруженное локально изображение |
| `img_url` | `URLField` | Внешняя ссылка на картинку |
| `evolution_from` | `ForeignKey('self')` | Предыдущая эволюция. Через `related_name='evolutions'` даёт доступ к последующим формам |

#### Связи:
У одного `Pokemon` может быть много `PokemonEntity` (особей).

`evolution_from` образует направленную связь «предок → потомки»

### `Pokemon_entity` - конкретная особь на карте
| Поле | Тип | Описание |
|------|-----|----------|
| `subject` | `ForeignKey(Pokemon)` | Какой вид покемона |
| `latitude` | `FloatField` | Широта |
| `longitude` | `FloatField` | Долгота |
| `appeared_at` | `DateTimeField` | Дата и время появления (`null` – доступен всегда) |
| `disappeared_at` | `DateTimeField` | Время исчезновения (`null` – не исчезает) |
| `pokemon_lvl` | `IntegerField` | Уровень |
| `pokemon_hlth` | `IntegerField` | Здоровье |
| `pokemon_strength` | `IntegerField` | Сила |
| `pokemon_def` | `IntegerField` | Защита |
| `pokemon_stam` | `IntegerField` | Выносливость |

## Основные страницы

### Главная – `/` (функция `show_all_pokemons`)
- Отображает карту Москвы с маркерами **только актуальных особей** (текущее время между `appeared_at` и `disappeared_at`).
- Внизу – список всех видов покемонов с иконками и ссылками на детальную страницу.

### Детальная страница покемона – `/pokemon/<id>/` (функция `show_pokemon`)
- Карта со всеми особями этого покемона (можно показывать и неактуальные).
- Информация: названия (рус., англ., яп.), описание, картинка.
- Если есть **предыдущая эволюция** – ссылка на неё.
- Если есть **следующие эволюции** (потомки через `evolution_from`) – ссылки на них.

## Примеры использования

### Добавление покемона через админ-панель
1. Зайдите в `/admin` (требуется права суперпользователя).
2. В разделе `Pokemon` нажмите «Добавить».
3. Заполните поля: `title = Бульбазавр`, `title_en = Bulbasaur`, загрузите картинку.
4. Для эволюции: в поле `evolution_from` укажите предка (например, Бульбазавр).
5. Сохраните.
